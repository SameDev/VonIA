# Contribuindo para a VonIA

Obrigado por considerar contribuir com a **VonIA**, a assistente cognitiva open source para estudantes de programação e ciências da computação.  
Nosso objetivo é construir uma IA educacional robusta, ética e tecnicamente excelente — e sua participação é essencial para isso.

Abaixo estão as diretrizes para mantermos o projeto organizado, seguro e escalável.

---

## Princípios Fundamentais

- **Clareza acima de tudo** — código e documentação devem ser diretos e explicativos.  
- **Qualidade técnica** — a VonIA é uma ferramenta educacional; contribuições devem fortalecer a precisão e a arquitetura.  
- **Respeito** — discutimos ideias, nunca pessoas.  
- **Evolução contínua** — cada PR deve mover o projeto adiante de forma incremental.

---

## Como Começar

1. Faça um fork do repositório.  
2. Crie um branch para a sua feature ou correção:
```git checkout -b feature/nome-da-feature```
3. Desenvolva sua contribuição seguindo o estilo do projeto.  
4. Garanta que o código foi testado localmente.  
5. Abra um Pull Request descrito claramente.

---

## Requisitos de Código

### **Estilo**
- Python: seguir PEP8  
- Estruturas devem ser modulares e fáceis de testar

### **Testes**
Antes de enviar o PR:

- Execute testes locais  
- Valide funcionamento básico do treino  
- Teste a API manualmente (quando aplicável)

---

## Contribuições de Machine Learning

Ao contribuir para o núcleo:

1. **Explique claramente o propósito da modificação.**  
2. Justifique alterações de modelo, tokenizador ou dataset.  
3. Não suba pesos de modelos diretamente no repositório.  
4. Use datasets limpos e revisados, IA educacional exige rigor, para mantermos precisão sempre.

---

## Documentação

Toda nova feature deve vir acompanhada de documentação mínima:

- O que faz  
- Como usar  
- Exemplos  
- Limitações (se houver)

---

## Pull Requests

Antes de abrir um PR:

- Sincronize seu branch com `main`
- Escreva uma descrição objetiva:  
- _O que mudou?_  
- _Por quê?_  
- _Impacto do PR?_  

PRs sem descrição clara podem ser recusados.


## Como Ajudar Mesmo Sem Codar

- Reporte bugs  
- Melhore documentação  
- Sugira melhorias  
- Teste novas versões  
- Ajude novos contribuidores  

---

## Obrigado por impulsionar a VonIA

Cada contribuição constrói uma ferramenta mais inteligente, acessível e impactante para estudantes de tecnologia no mundo todo.

Seja bem-vindo(a) ao ecossistema VonIA.
